# pixel-maddin.github.io

Nur für die Android-App von [Punsch & Lichterglanz](https://pixel-maddin.github.io/Punsch-und-Lichterglanz/):
`.well-known/assetlinks.json` bestätigt, dass die App zur Webseite gehört - dann zeigt sie das Spiel
ohne Adressleiste. `.nojekyll` sorgt dafür, dass GitHub Pages den Ordner `.well-known` überhaupt ausliefert.
